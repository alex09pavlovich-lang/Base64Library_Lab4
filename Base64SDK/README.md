\# Base64Library SDK



\## 1. Загальна інформація



\*\*Base64Library\*\* — це динамічна бібліотека мовою C++, призначена для кодування та декодування даних у форматі Base64.



Бібліотека надає чотири основні функції:

\- `encode()` — кодування даних у Base64.

\- `decode()` — декодування даних із Base64.

\- `encodedSize()` — обчислення розміру закодованих даних.

\- `isValid()` — перевірка правильності Base64-рядка.



Бібліотека використовує C-linkage (`extern "C"`) для сумісності імен експортованих функцій.



\## 2. Склад SDK-пакунка



\- `include/base64.h` — заголовочний файл із оголошеннями функцій.

\- `lib/Base64Library.lib` — бібліотека імпорту для неявного зв'язування.

\- `bin/Base64Library.dll` — динамічна бібліотека.



\## 3. Опис API



\### 3.1. encodedSize()



\*\*Сигнатура:\*\*

`std::size\_t encodedSize(std::size\_t inputSize);`



\*\*Призначення:\*\* обчислює кількість символів, необхідних для представлення вхідних даних у форматі Base64.



\*\*Вхідні параметри:\*\*

\- `inputSize` — кількість байтів вхідних даних.



\*\*Результат:\*\* повертає необхідний розмір закодованого рядка за формулою:



`4 \* ((inputSize + 2) / 3)`



У разі переповнення повертається максимальне значення `std::size\_t`.



\### 3.2. encode()



\*\*Сигнатура:\*\*



`bool encode(const std::uint8\_t\* input, std::size\_t inputSize, char\* output, std::size\_t outputCapacity, std::size\_t\* outputSize);`



\*\*Призначення:\*\* кодує вхідні байти у формат Base64.



\*\*Вхідні параметри:\*\*

\- `input` — вказівник на вхідні дані.

\- `inputSize` — розмір вхідних даних у байтах.

\- `output` — буфер для результату.

\- `outputCapacity` — доступна місткість вихідного буфера.

\- `outputSize` — вказівник на змінну, у яку записується фактичний розмір результату.



\*\*Результат:\*\*

\- `true` — кодування виконано успішно.

\- `false` — сталася помилка.



Вихідний буфер повинен мати місткість не меншу за `encodedSize(inputSize)`. Символ завершення рядка `'\\0'` автоматично не додається.



\### 3.3. decode()



\*\*Сигнатура:\*\*



`bool decode(const char\* input, std::size\_t inputSize, std::uint8\_t\* output, std::size\_t outputCapacity, std::size\_t\* outputSize);`



\*\*Призначення:\*\* декодує Base64-рядок у початкові байтові дані.



\*\*Вхідні параметри:\*\*

\- `input` — вказівник на Base64-рядок.

\- `inputSize` — довжина вхідного рядка.

\- `output` — буфер для декодованих даних.

\- `outputCapacity` — доступна місткість вихідного буфера.

\- `outputSize` — вказівник на змінну для збереження фактичного розміру результату.



\*\*Результат:\*\*

\- `true` — декодування виконано успішно.

\- `false` — вхідні дані некоректні або виникла помилка.



Вхідний рядок повинен відповідати формату Base64. Розмір вихідного буфера повинен бути достатнім для збереження результату.



\### 3.4. isValid()



\*\*Сигнатура:\*\*



`bool isValid(const char\* input, std::size\_t inputSize);`



\*\*Призначення:\*\* перевіряє, чи відповідає переданий рядок формату Base64.



\*\*Вхідні параметри:\*\*

\- `input` — вказівник на рядок для перевірки.

\- `inputSize` — довжина рядка.



\*\*Результат:\*\*

\- `true` — рядок відповідає правилам Base64.

\- `false` — рядок містить некоректні символи, неправильне заповнення або має неправильну довжину.



\## 4. Граничні умови та обробка помилок



1\. Порожні вхідні дані допускаються.

2\. Нульова довжина вхідних даних обробляється коректно.

3\. Якщо вхідний вказівник дорівнює `nullptr`, а довжина більша за нуль, функція повертає помилку.

4\. Якщо вихідний буфер недостатнього розміру, функція повертає `false`.

5\. Якщо `outputSize` дорівнює `nullptr`, функції `encode()` та `decode()` повертають `false`.

6\. При помилці `encode()` та `decode()` встановлюють `\*outputSize = 0`, якщо сам вказівник `outputSize` не дорівнює `nullptr`.

7\. Для коректного Base64 довжина рядка повинна бути кратною чотирьом.

8\. Символи заповнення `=` можуть знаходитися тільки наприкінці рядка.



Для успішного виконання операцій необхідно передавати коректні вказівники та достатній розмір буферів.



\## 5. Приклад використання



```cpp

\#include "base64.h"

\#include <iostream>

\#include <string>

\#include <vector>



int main() {

&#x20;   std::string text = "Hello, Base64!";



&#x20;   std::vector<char> encoded(encodedSize(text.size()));

&#x20;   std::size\_t encodedLength = 0;



&#x20;   if (!encode(

&#x20;       reinterpret\_cast<const std::uint8\_t\*>(text.data()),

&#x20;       text.size(),

&#x20;       encoded.data(),

&#x20;       encoded.size(),

&#x20;       \&encodedLength

&#x20;   )) {

&#x20;       return 1;

&#x20;   }



&#x20;   std::string result(encoded.data(), encodedLength);



&#x20;   std::cout << "Encoded: " << result << std::endl;

&#x20;   std::cout << "Valid: " << isValid(result.data(), result.size())

&#x20;             << std::endl;



&#x20;   return 0;

}

```



\## 6. Підключення бібліотеки



Для неявного зв'язування необхідно:

\- Підключити `base64.h`.

\- Додати `Base64Library.lib` до налаштувань лінкування.

\- Забезпечити доступність `Base64Library.dll` під час запуску програми.



Для явного зв'язування використовується тільки `Base64Library.dll`. Завантаження виконується за допомогою `LoadLibrary()`, а отримання адрес функцій — через `GetProcAddress()`. Заголовочний файл та `.lib` для цього способу не використовуються.
